**PowerShell Community Call – August 2026 Detailed Summary**

**Opening & Celebrations:**

- Jason welcomed attendees and celebrated PowerShell's 20th anniversary (release was in November). Ryan Yates also noted that this past Tuesday marked 10 years since PowerShell went open source — Jason flagged it for Sean to add to the regular celebration list. 2:00

**Release Updates:**

- Justin Chung announced PowerShell 7.4.19, 7.5.10, and 7.6.5 are available. Release tempo has improved with monthly cadence. The team has begun testing sim-shipping with .NET — not yet in these releases, but a meaningful step toward that goal. 3:54

**DSC v3 Updates:**

- Steve Lee announced DSC 3.3 RC2 is targeting release today (or Monday to avoid a Friday ship). Key change from RC1: design improvements to the Windows Firewall resource based on community feedback to support both auditing and rule-setting scenarios. 5:14
- DSC v3 is now publishing Linux packages (RPMs and debs) to packages.microsoft.com starting with 3.3 RC1. 6:30
- DSC 3.3 GA is targeted for early-to-mid September. DSC 3.4 planning is underway. Notable items tagged for 3.4: OpenTelemetry for tracing, a new **Actions** type (for imperative operations like killing a process or rebooting — distinct from state-based resources), DSC as an SSH subsystem for one-to-many management at scale, ORAS/OCI integration, Python adapter (community draft PR already open), and signing support for resource manifests and configuration documents. 7:30
- Steve shared a draft RFC on a new PowerShell authoring experience for DSC configurations — a replacement for the `configuration` keyword. Encourages feedback especially from DSC v2 users familiar with the configuration keyword experience. Link posted in chat. 9:29

**Community News — PowerShell Podcast & Wednesday Stream:**

- Andrew Pla highlighted recent podcast episodes (Jake Hildreth, Fred) and is looking for new guests — reach out via Discord or LinkedIn. Exploring a multi-guest conversation format. PowerShell Wednesday stream is also open to first-time speakers for demos or live coding. 11:35

**Open Source Stewardship Program:**

- Gilbert Sanchez described the community module revival program launched at Summit. Goal: give ongoing support to important community modules whose maintainers have moved on. Plaster and PS Depends are already being stewarded; Andrew Pla is taking on PS Cohens; PS Build Helper is also incoming. Stewards act as project managers — technical depth not required. Governance model and playbooks available at the PowerShell org on GitHub. Community members interested in stewarding a module can reach out. 13:04

**PMC Package Update:**

- Anam announced Ubuntu 26.04 support on packages.microsoft.com, starting with the PowerShell 7.7.0 preview release and forward. 16:38

**Documentation Update:**

- Sean Wheeler: Recent focus on release documentation for new releases and continued Script Analyzer rules cleanup — every rule now has a configuration section, even if it's not configurable. New in 7.7: `New-Guid` now creates version 7 UUIDs (time-sortable), a technically breaking change with minimal practical impact. Sean also completed an overhaul of the PowerShell Config documentation — important groundwork as the team prepares to make the user data directory (modules, profiles, help) relocatable in upcoming releases. 17:26

**Demo: Customizable User-Scoped Content Path:**

- Justin Chung demoed two new cmdlets: `Get-PSContentPath` and `Set-PSContentPath`. These consolidate user-scoped content (scripts, modules, profile, help) into a single configurable location defined in the PowerShell config file. A tiered fallback system is in place: new location → OneDrive location → defaults (AppData). James Brundage suggested Push/Pop verbs to enable work-tree-style switching between content paths. PR open on GitHub. 21:12

**Demo: MSIX Machine-Folder Fix:**

- Justin Chung demoed the machine-wide config fix for MSIX installations. Currently, PS Home is not writable even as admin under MSIX, blocking things like `Set-ExecutionPolicy -Scope LocalMachine`. The fix moves machine-wide config to ProgramData, with channel-specific paths (LTS, stable, preview each get their own location). This is expected to resolve many of the known MSIX limitations. PR open on GitHub. Master MSIX tracking issue link posted in chat. 28:04

**Demo: PSResourceGet Concurrency Improvements:**

- Amber Erickson demoed major performance improvements in PSResourceGet 1.3.0-preview1. Key results: finding the Az module (100+ dependencies) dropped from ~1 minute to ~6 seconds; installing Az dropped from 3m32s to 1m17s. Improvements come from concurrency for both parent packages and dependencies across all server types, plus caching of dependency lookups and network calls. A new release incorporating additional improvements is expected within a few weeks. Feedback on preview1 issues welcome. 33:09

**Security Alert — Gallery Typosquatting:**

- Ryan Yates flagged a typosquatting attack on the PowerShell Gallery that occurred this week, with credential-stealing packages published targeting common typos. The same wave hit npm and Ruby. Steve Lee confirmed the Gallery team is actively working through the situation and evaluating future mitigations. Community members encouraged to double-check module names before installing. 38:32
